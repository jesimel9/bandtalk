Fonctions

Tout ce qu’il faut pour jouer ensemble.

BandTalk remplace l’intercom et les gestes de scène par vos téléphones, avec un son clair et un très faible délai.

Intercom en temps réel

Appui pour parler ou micro ouvert. Anti-écho, anti-bruit, et une « portée du micro » qui ne transmet que la voix proche du téléphone.

Wi-Fi local, sans Internet

Un téléphone crée la session, les autres scannent son QR code. Fonctionne avec un routeur ou le partage de connexion du chef, même sans forfait.

Mode Internet / 4G

Quand il n’y a pas de Wi-Fi commun : la session passe par Internet, avec suppression de bruit par intelligence artificielle.

Signaux de scène

Refrain, fin, alerte son… Un signal s’affiche en plein écran sur tous les téléphones, avec le décompte « one, two, three, four » calé sur le temps.

Métronome partagé

Le même clic, au même moment, dans les oreilles de tout le groupe.

Studio : enregistrer vos répétitions

Enregistrez une prise en haute qualité, réécoutez-la tout de suite et partagez-la avec le groupe (WhatsApp, e-mail…).

Sur scène

Chacun s’entend, tout le monde suit.

Guitare, voix, percussions, cuivres, louange… Avec BandTalk, le chef parle à tout le groupe ou à une seule section, sans quitter son instrument.

Tutoriel en images

BandTalk pas à pas.

Les vrais écrans de l’appli, dans l’ordre. Choisissez une rubrique : la connexion, le mode Wi-Fi local (sans Internet), ou le mode 4G / Internet.

Créer son compte et se connecter

Il faut Internet une seule fois, pour créer le compte. Ensuite, BandTalk fonctionne sur scène même sans Internet (en Wi-Fi local). Votre compte garde votre abonnement, même si vous changez de téléphone.

  1. Ouvrez BandTalk

    Touchez Continuer avec Google (le plus simple), ou entrez votre e-mail et votre mot de passe si vous avez déjà un compte.

  2. Ou créez un compte

    Onglet S’inscrire : votre nom de scène, votre numéro Wave (pour reconnaître vos paiements), votre e-mail et un mot de passe.

  3. Vous êtes à l’accueil

    Deux gros boutons : Créer une session pour le chef, Rejoindre pour les musiciens. Choisissez ensuite le Wi-Fi local ou la 4G.

Session en Wi-Fi local, sans Internet

C’est le mode le plus réactif. Tous les téléphones doivent être sur le même Wi-Fi : un routeur (idéalement en 5 GHz), ou le partage de connexion du téléphone du chef. Pas besoin de forfait Internet : seul le Wi-Fi sert.

  1. Le chef crée la session

    Créer une session › donnez-lui un nom › choisissez Wi-Fi › Lancer la session.

  2. Il invite les musiciens

    Touchez Inviter : un QR code et un code PIN à 6 chiffres s’affichent. Montrez-les au groupe, ou partagez l’invitation par WhatsApp.

  3. Les musiciens rejoignent

    Rejoindre › Wi-Fi local › scannez le QR code, ou tapez le PIN puis Entrer. La session apparaît aussi toute seule dans « À proximité ».

  4. On joue !

    Maintenez le gros bouton MAINTENIR pour parler (ou passez en « Mains libres »). Lancez le métronome : tout le monde entend le même clic.

  5. Envoyez un signal

    Plus bas dans l’écran Live : Solo, Refrain, Break, Reprise, Stop… Un toucher suffit, à tout le groupe ou à une seule section.

  6. Tout le groupe le voit

    Le signal s’affiche en plein écran sur chaque téléphone, avec un décompte calé sur le temps, jusqu’au « GO ».

Session par Internet (4G ou 5G)

Quand les musiciens ne sont pas sur le même Wi-Fi, ou sont loin les uns des autres. Chaque téléphone a besoin d’Internet (4G, 5G ou n’importe quel Wi-Fi). La voix passe par des serveurs : le délai est un peu plus grand qu’en Wi-Fi local.

  1. Choisissez « 4G / 5G »

    Créer une session › un nom › touchez 4G / 5G › Lancer la session. Quelques secondes suffisent pour l’ouvrir.

  2. Partagez le code

    Inviter affiche « Session Internet », le code et le QR code. Le plus pratique à distance : Partager l’invitation par WhatsApp.

  3. Les musiciens rejoignent

    Rejoindre › onglet Internet › scannez le QR code ou tapez le code, puis Entrer.

  4. Même écran Live

    Parler, métronome, signaux, volume de chacun : tout fonctionne comme en Wi-Fi local. Pour un meilleur son, utilisez des écouteurs filaires.

Guide

Bien utiliser BandTalk.

Pendant le concert : parler, signaux, métronome
  • Parler : maintenez le gros bouton, ou passez en micro ouvert (« Mains libres »).
  • Volume de chacun : réglez le volume de chaque musicien dans l’écran Live.
  • Signaux : un toucher envoie le signal en plein écran à tout le groupe, avec un décompte vocal calé sur le prochain temps fort. Un toucher sur le plein écran le ferme.
  • Métronome : le même clic pour tout le monde ; son volume est partagé.
Rien n’apparaît en Wi-Fi local ?

Vérifiez que tous les téléphones sont sur le même Wi-Fi. Sinon, sur le téléphone du chef : écran Live › Inviter › notez l’adresse et le port, puis chez le musicien : Rejoindre › Connexion manuelle (adresse IP).

Portée du micro : ne transmettre que votre voix

Dans Réglages › Portée du micro (1,5 m par défaut), BandTalk coupe ce qui vient de loin : batterie, ampli, public. Faites une fois Calibrer ma voix : téléphone ou micro du casque à sa place habituelle, parlez normalement 5 secondes. Recommencez si vous changez de casque.

Studio : enregistrer une répétition

Dans l’onglet Studio, touchez Enregistrer : la prise est enregistrée en haute qualité (WAV 44,1 kHz). Réécoutez-la aussitôt, puis partagez-la avec le groupe (WhatsApp, e-mail…).

Les prises restent sur votre téléphone : rien n’est envoyé sur Internet.

Conseils pour un son sans délai
  • Écouteurs filaires : un casque Bluetooth ajoute un délai (150 à 250 ms) et de l’écho.
  • Routeur en 5 GHz, placé près de la scène.
  • Appui-pour-parler tant que tout le monde n’a pas d’écouteurs.
  • Écran Live › menu ⋮ › Diagnostic réseau : un ping sous 10 ms signifie un Wi-Fi sain.

Questions fréquentes

Vous vous demandez…

Faut-il Internet pour utiliser BandTalk ?

Non pour jouer en Wi-Fi local : un Wi-Fi commun suffit, même sans connexion Internet. Internet est nécessaire pour créer votre compte, payer l’abonnement, et pour les sessions en mode 4G / Internet.

Combien de musiciens par session ?

Jusqu’à 8 téléphones par session.

Qui doit payer ?

Chaque utilisateur, qu’il crée ou qu’il rejoigne les sessions, après ses 2 sessions d’essai gratuites.

L’essai gratuit est lié au téléphone : désinstaller puis réinstaller BandTalk, ou créer un autre compte, ne redonne pas de sessions gratuites. Une connexion à Internet est nécessaire une première fois pour activer l’essai.

J’ai payé par Wave : quand mon abonnement est-il activé ?

Avec le bouton Payer avec Wave de l’appli : revenez simplement dans BandTalk, l’abonnement s’active tout seul en quelques secondes. Par transfert au numéro Wave : dans Compte › Abonnement, saisissez l’identifiant de la transaction ; l’activation se fait après vérification, en général en moins de 24 h.

Et si mon abonnement se termine pendant un concert ?

Une session déjà ouverte continue normalement. BandTalk vous prévient 3 jours avant la fin.

Pourquoi BandTalk n’est-il pas sur le Play Store ?

Pour l’instant, BandTalk est distribué directement sur ce site. C’est pourquoi Android demande d’autoriser l’installation (voir « Télécharger »). Téléchargez BandTalk uniquement depuis ce site.

Et sur iPhone ?

BandTalk fonctionne pour l’instant uniquement sur Android.

Quelles données sont collectées ?

Votre compte (nom, e-mail, téléphone), des statistiques d’utilisation (fréquence, durée, sessions créées) et, seulement si vous l’acceptez, votre ville. Votre position exacte, vos conversations et vos enregistrements ne sont jamais enregistrés par BandTalk. Tout est expliqué dans la politique de confidentialité.

Prêts à monter sur scène ?

Votre groupe, enfin sur la même longueur d’onde.
